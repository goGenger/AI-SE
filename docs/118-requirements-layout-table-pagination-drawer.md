## 4. 新增组件（components/ui）

- **Dialog**：Reka `DialogRoot → [DialogTrigger（可选 #trigger 插槽，as-child）] → DialogPortal → DialogOverlay + DialogContent（DialogTitle / DialogDescription / DialogClose）`；`v-model:open`、`title` 必需、`description` 可选（未提供时移除悬空的 `aria-describedby`）。
- **Drawer**：同一原语族 + 右侧贴边版式（`inset-y-0 right-0 w-[min(720px,92vw)]` 全高）；未采用 Reka 的手势 Drawer 原语 —— 桌面控制台无滑动 / 吸附语义，避免第二套交互面。
- 两个刻意的实现决定（供维护者理解）：
  1. `unmount-on-hide="false"`：**关闭态内容保持挂载**（`display:none` 隐藏）——保证本仓库 SSR 字符串测试可经 `ctx.teleports` 断言弹窗 / 抽屉内容，且表单字段值跨开关保持；关闭态安全性已核对 Reka 源码与实测（`present=false` 时不接管焦点、不拦 Esc / 外部点击、不禁用 body 指针事件）。
  2. Portal `force-mount`：SSR / 首帧即输出 Teleport 内容（本应用为纯客户端渲染，仅影响挂载时机）。
- 样式全部 Design Token（`--card` / `--border` / `--card-padding` / `--radius-lg` / `--shadow-overlay`；遮罩 `bg-foreground/40`）；无新依赖、无全局样式改动。
