## 2. 布局与交互变化

| #   | 区域     | 变化                                                                                                                                                                                                                                                                                                         |
| --- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 页头     | 「新建工作流」为独立按钮（Dialog trigger 插槽：`aria-haspopup="dialog"` / `aria-expanded`）；创建表单（项目 / 需求 / 路径 / 并发 / 重试 / 策略 / 预算×3 / 审批勾选…）整体移入 Dialog（宽 560），字段、约束与文案原样                                                                                         |
