## E-0 —— 修复 C-6 阻断项（明细）

**（a）红灯语义细分**（C-6 发现 1）

- 现状：`planVerificationChecks` 对所有 `TEST` 任务产出 `expectation:"fail"` 的测试检查；实现完成后的回归测试合法全绿 → 被覆盖为 FAILED（run-1 T-13：套件 8/8 AC 断言通过仍判空转）。
- 修复方向（默认）：期望翻转条件化为「**该测试任务覆盖的 AC 全部已有 verified 实现证据** → 期望改为 pass（回归验证）；否则保持 fail（红灯）」。证据来源：同工作流内已完成任务的 `output.verification`（verdict=verified 且 `acResults` 覆盖相应 acKey）。
- 实现约束：条件计算放 server 侧（`verifyingTaskExecutor`/`taskVerifier` 层，可查同工作流任务）；**不改引擎**；无证据可查时保守保持红灯（fail-closed）。
- 先写复现用例（两个方向）：① 实现已完成 + 测试全绿 → 不得覆盖 FAILED（修复后绿）；② 实现未完成 + 空转测试全绿 → 仍判 FAILED（红灯保持）。
- 语义变更声明：写入 `docs/126`（含对 C-6 run-1 结果的重新解释）。

**（b）超时终止传播**（C-6 发现 2/3）

- 现状：`timed_out` 的 agent_run 死后仍持续工具调用（+2/+4/+10/+23min 四例；幽灵写工作区、烧未记账 token）。
- 顺序：① 复现（脚本化模型 + 短 `timeoutMs` + 长工具循环 → 断言超时后零新增 tool_calls/事件/写入）；② 定位（AgentGraph 节点间 abort 检查、工具执行期中止传播、run 收尾时序）；③ 最小修复（目标语义：timeout 裁定后该 run 零新增调用与零持久化写入）；④ 回归（既有超时用例保持绿）。
- **时间盒**：若根因位于 LangGraph/deepagents 内部且 4h 内不可修，先落**止损层**（执行器收尾强制中止 + 记录器拒收 + 防死后写入）并登记深修项——止损层须有测试（同样的复现断言）。
- 记账补全：timed_out 时若 usage 可得则落库；不可得如实记 0（记录中注明）。
